# IT Энциклопедия — Учебный справочник по информатике

Веб-справочник и набор интерактивных мини-модулей для изучения базовых понятий информатики. Проект задуман как понятный и структурированный конспект с быстрым поиском и практикой.

🔗 **Демо (GitHub Pages):** https://artevio1.github.io/Guide-to-Computer-Science/

## Основные разделы и возможности

- **Справочник терминов (`index.html`)** — краткие определения ключевых понятий информатики, навигация по разделам, поиск по терминам и модальное окно (`<dialog>`) с расширенным описанием и ссылкой на статью в Википедии.
- **Мемори (`memory.html`)** — тренировка памяти и ассоциаций на базе терминов и концепций информатики.
- **Викторина (`quiz.html`)** — интерактивная проверка знаний по изученным темам.
- **Двоичный код (`binary.html`)** — модуль для работы с двоичной системой счисления и переводами значений.

## Стек технологий

- **HTML5** (семантическая разметка, `<dialog>`, ARIA-атрибуты для доступности)
- **CSS3** (оформление интерфейса, адаптивность, Google Fonts)
- **JavaScript** (динамическая фильтрация/поиск, логика модального окна и интерактивных модулей)
- **GitHub Pages** (хостинг и публикация проекта)
